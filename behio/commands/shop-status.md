description: Show what is done and what is still missing in your Behio shop
---

Use the Behio tools to report the state of the user's shop: `list-organizations`,
`site-list` (the sites that sell; ask which one if there are several, its `eshopId` equals
its `siteId`), `eshop-onboarding-get`,
`eshop-products-list` (count published and draft products), `eshop-payment-methods-list`,
`eshop-shipping-methods-list` and `site-get` with the preview URL. Answer as a short
checklist with done and missing items and the next step, in the user's language.
