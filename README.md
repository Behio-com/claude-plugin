# Behio plugins for Claude

Official [Behio](https://behio.com) plugins for Claude Code and the Claude desktop app.

## behio

Launch a complete online shop or website on Behio straight from Claude: products with
photos and texts, payments, legal pages, a storefront with an instant preview, hosting and
your own domain. Claude guides you step by step; a first working shop typically takes 30 to
60 minutes.

```
/plugin marketplace add Behio-com/claude-plugin
/plugin install behio@behio
```

Then run `/mcp`, pick `behio` and sign in to Behio. Start with `/behio:new-shop` or just say
"I want to sell my products online". Details in [behio/README.md](behio/README.md).
